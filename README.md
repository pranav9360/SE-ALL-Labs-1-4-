# Software Engineering Labs 1–4

**Course:** Software Engineering Laboratory  
**Project:** Patient Health Record Consent Management System (Labs 1–3)

This repository consolidates the deliverables for Software Engineering Labs 1–4. The original lab repositories remain unchanged.

## Repository layout

- **Lab-1-Requirements/** — requirements and associated deliverables.
- **Lab-2-Jira/** — Agile backlog, Jira evidence, report and reflection.
- **Lab-3-Architecture/** — use-case and component diagrams, requirements and architecture justification.
- **Lab-4-Minesweeper/** — Minesweeper assignment source, task prompt and before/after demonstration videos.

## Lab summaries

### Lab 1 — Requirements
Contains requirements documentation for the Patient Health Record Consent Management System, including functional requirements for time-bounded consent, revocation, record selection, access requests, and consent history, as well as audit and performance requirements.

### Lab 2 — Jira: Agile Backlog Creation & Sprint Simulation
Contains the Jira deliverables, screenshots and report. The backlog is organized around Consent Management, Consent Revocation & History, and Medical Record Access & Audit.

### Lab 3 — Architecture Design
Contains the UML use-case diagram and UML component diagram for a layered architecture (Presentation, Business/Service, and Data/Integration), along with requirements and the architecture selection justification.

### Lab 4 — Minesweeper
Contains the Minesweeper task prompt, source files, dependency declaration and before/after gameplay recordings. Review the Lab 4 README for setup, tasks and submission notes.
