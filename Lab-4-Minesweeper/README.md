# Lab 4 — Minesweeper

This folder contains the task prompt, Python source files, requirements file, and before/after gameplay demonstration videos.

## Files

- `Minesweeper_Lab4_4_Task_Prompts.pdf` — assignment tasks and submission guidance.
- `main.py`, `game.py`, `board.py` — project source.
- `requirements.txt` — dependency declaration.
- `before.mp4` — gameplay before changes.
- `after.mp4` — gameplay after changes.

## Run

Use Python 3.9 or newer:

```bash
python main.py
```

No package installation is required according to the original project instructions.
